# Unsent: The Micro-Confession Sprint

A two-part micro-confession for the [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) bounty on make.fun.

`main.ts` writes a single unsent message to `/output/entry.txt`: a `To:` line naming who it was meant for, and the message itself, one line, exactly as it was typed — a small, specific, quietly heartbreaking confession about an umbrella left behind on the last train home in August, and the mornings spent checking the rain ever since. No explanation follows it; the reason it stayed in drafts is felt in the words, not stated.

Run with Node 22: `node main.ts` (set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written).
